# Fly Hero Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A browser page where a FlyWire-connectome spiking model learns a 3-lane rhythm game through dopamine-gated plasticity. It runs against a REINFORCE readout baseline and against wiring/dopamine controls.

**Architecture:**
- **Offline.** A Python script extracts a 3,371-neuron right-hemisphere mushroom-body subgraph and a 139k-point brain cloud.
- **Shared code.** Plain ES modules (`sim`, `game`, `agents`) run unchanged in Node, for tests and experiments, and in the browser, for the live page.
- **Browser page.** `app.js` draws the game and charts on canvas, and `brain.js` draws the WebGL brain.

**Tech Stack:** Python 3 (pandas, pyarrow) for extraction only; vanilla JS ES modules; Node 24 for tests and experiments; no npm dependencies.

**Spec:** `docs/superpowers/specs/2026-09-15-fly-hero-design.md`

**Execution note:** Ben asked for unattended completion, so this plan is executed inline in one session. Code is written in the task and is not duplicated here. Each step keeps its exact verification command and expected result.

## Global Constraints

- No frameworks, no npm dependencies, no build step. Plain HTML + CSS + ES modules. The page must run from `python -m http.server`.
- Only true numbers in the UI: neuron and synapse counts come from `subgraph.json` meta, and "spiking now" from live simulator state.
- Anything simulated is labeled simulated; the nerve cord is labeled schematic.
- No branded assets. The name is "Fly Hero", songs are generated tones, and song names are original.
- README claims must match `data/results.json`. If real wiring doesn't beat shuffled, say so.
- LIF parameters: v0 = −52 mV, v_th = −45 mV, τ_m = 20 ms, τ_syn = 5 ms, w_syn = 0.275 mV, Poisson 150 Hz with a 250 × w_syn kick, dt = 1 ms, delay 2 ms, refractory 2 ms.
- Timing: 400 ms slots; VPN drive from t−200 to t+40; decision window t−150 to t+40; press at t+40; dopamine t+40 to t+140; human window ±150 ms.
